# 1. 프로젝트 개요

## 프로젝트명

**ZipAI (집아이)**

## 프로젝트 소개

ZipAI는 청년 및 사회초년생이 안전한 주거를 선택할 수 있도록 지원하는 **AI 기반 청년 주거 안전 플랫폼**이다.

현재 부동산 플랫폼은 가격, 위치, 옵션 등의 정보는 제공하지만 실제 계약 시 중요한 전세사기 위험, 주변 치안, CCTV 설치 여부,
여성 안심 귀갓길, 범죄 발생 정보 등은 여러 기관의 사이트를 각각 방문해야 확인할 수 있다.

ZipAI는 이러한 문제를 해결하기 위해 공공데이터와 지도 서비스를 통합하여 하나의 플랫폼에서 다양한 주거 안전 정보를 제공하는 것을 목표로 한다.

또한 계약 전부터 계약 후까지 필요한 안전 정보를 단계별로 제공하여 안전한 부동산 거래를 지원한다.

---

# 2. 플랫폼 이름(ZipAI)인 이유

ZipAI는 "Zip"과 "AI"를 결합한 이름이다.

### Zip

- 집(Home)
- 주소(Zip Code)
- 주거 공간

이라는 의미를 담고 있다.

### AI

- Artificial Intelligence
- 위험도 분석
- 데이터 기반 안전 예측

을 의미한다.

즉,

> **"AI가 분석해주는 가장 안전한 집 찾기 플랫폼"**

이라는 의미를 가지고 있으며, 누구나 쉽게 기억할 수 있는 브랜드 네이밍을 목표로 하였다.

---

# 3. 기획 의도

청년들이 자취나 전·월세 계약을 준비할 때 가장 많이 하는 고민은 다음과 같다.

- 이 집은 안전한가?
- 전세사기를 당하지 않을까?
- 밤에도 안전하게 다닐 수 있을까?
- CCTV는 충분히 설치되어 있을까?
- 주변 범죄는 많이 발생하는 지역일까?

하지만 이러한 정보는

- 부동산 플랫폼
- 경찰청
- 생활안전지도
- 국토교통부
- 각 지자체

등 여러 사이트에 분산되어 있어 사용자가 일일이 찾아야 하는 불편함이 존재한다.

ZipAI는 이러한 불편함을 해결하기 위해 필요한 정보를 하나의 플랫폼으로 통합하여 제공하도록 기획하였다.

---

# 4. 문제 제기

현재 대부분의 부동산 플랫폼은

- 가격
- 위치
- 면적
- 옵션

등 거래 중심의 정보만 제공한다.

그러나 실제 거주를 결정할 때는

- 범죄 위험도
- 치안 수준
- 여성 안전
- CCTV 설치 현황
- 전세사기 위험

등이 더욱 중요한 요소가 된다.

특히 사회초년생과 대학생은 관련 정보를 얻기 어려워 계약 과정에서 많은 위험에 노출될 수 있다.

따라서 다양한 공공 데이터를 하나의 플랫폼에서 제공하는 서비스가 필요하다.

## 반응형 기준

Bootstrap 5 중단점을 그대로 사용했다.

| 구분 |   너비 | 컨테이너 |
| ---- | -----: | -------: |
| sm   |  576px |    540px |
| md   |  768px |    720px |
| lg   |  992px |    960px |
| xl   | 1200px |   1140px |
| xxl  | 1400px |   1320px |

- `767.98px` 이하에서는 사이트맵을 숨긴다.
- 모바일에서는 브랜드, 고객센터, 패밀리사이트 및 회사 정보를 중앙 정렬한다.
- md에서는 패밀리사이트 영역을 전체 폭으로 배치하고 lg부터 3열 레이아웃으로 복귀한다.

다른 페이지에 적용할 때 `footer.html`의 `<footer class="homepick-footer">...</footer>`와 TOP 버튼을 옮기고, `<head>`에 다음 리소스를 연결한다.

1. Google Fonts CDN
2. Font Awesome CDN
3. `static/css/footer.css`
4. `static/images/favicon.svg`

`footer.css`에서 `common.css`를 `@import`하므로 페이지에서 `common.css`를 중복 연결할 필요는 없다.

## 1. 테스트 페이지

`test.html`은 브라우저에서 `hello 코덱스` 문구를 확인할 수 있는 기본 HTML 문서입니다.

## 2. 첫 번째 헤더

### 관련 파일

- `header.html`
- `static/css/header.css`

### 주요 특징

- 기존 ZipAI 푸터와 동일한 파란색 및 네이비 디자인 사용
- `section`, `nav` 태그 대신 `div` 요소로 구조 작성
- Flexbox를 이용한 로고, 메뉴, 버튼 배치
- 매물 찾기, 안전 진단, 전세 계산기, 계약 가이드, 체크리스트 메뉴 제공
- 검색, 로그인, 매물 등록 기능 배치
- 로그인 버튼을 매물 등록 버튼과 같은 크기의 주요 버튼으로 개선
- 화면 너비가 `992px` 미만일 때 햄버거 메뉴로 전환
- 모바일에서 로그인과 매물 등록 버튼을 같은 너비로 표시

### 로그인 버튼 디자인

- 로그인: 흰색 배경과 파란색 테두리
- 매물 등록: 파란색 배경과 흰색 글자
- 마우스를 올리면 색상과 위치가 자연스럽게 변경됨

## 3. 두 번째 헤더

### 관련 파일

- `headertwo.html`
- `static/css/headertwo.css`

### 주요 특징

- 첫 번째 헤더와 다른 차콜, 에메랄드, 코랄 색상 조합
- 매물 검색을 중심으로 한 2단 헤더 구조
- 지역 선택, 검색어 입력, 검색 버튼 제공
- 관심 매물과 로그인 기능 제공
- 아파트, 빌라·주택, 원룸·오피스텔 등 매물 카테고리 제공
- 안전 진단 메뉴에 `NEW` 표시 적용
- 별도의 내 매물 등록 버튼 제공
- `section`, `nav` 태그 없이 `div` 요소와 ARIA 역할 사용
- 전체 레이아웃을 Flexbox 방식으로 구현
- 화면 너비가 `992px` 미만일 때 카테고리를 접이식 메뉴로 전환

## 공통 리소스

두 헤더는 다음 프로젝트 리소스를 함께 사용합니다.

- `static/css/common.css`: 색상, 글꼴, 컨테이너, 반응형 기준
- `static/images/favicon.svg`: 브라우저 파비콘
- Google Fonts: IBM Plex Sans KR, Noto Sans KR
- Font Awesome 6.7.2: 메뉴 및 버튼 아이콘

## 확인 방법

프로젝트 루트에서 `header.html` 또는 `headertwo.html`을 브라우저로 열면 각 헤더를 확인할 수 있습니다.

모바일 메뉴는 브라우저 창의 너비를 `992px` 미만으로 줄인 뒤 오른쪽 메뉴 버튼을 눌러 확인합니다.
