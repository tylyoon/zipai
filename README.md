## 3. 프로젝트 개요

**ZipAI(집아이)**는 청년 및 사회초년생이 안전한 주거를 선택할 수 있도록 지원하는 **AI 기반 청년 주거 안전 플랫폼**입니다. 직방·다방과 같은 기존의 매물 탐색 플랫폼 모델을 바탕으로, 계약 시 반드시 확인해야 하는 전세사기 위험 정보와 지역별 안전 치안 데이터(CCTV, 비상벨, 경찰서 분포 등)를 시각화하여 사용자가 한눈에 안전도를 분석할 수 있도록 개발했습니다.

현재 프로젝트는 HTML, CSS, JavaScript 중심의 프론트엔드 프로토타입으로 이루어져 있으며, Leaflet.js 기반의 매물 탐색 지도, 위험안전도 히트맵 분석 페이지, 전세사기 예방 체크리스트 및 실시간 전세가율 계산기, 회원인증(로그인·회원가입) 및 마이페이지, 고객센터(FAQ 및 1:1 문의), 관리자 문의 제어 대시보드, 청년 맞춤형 금융지원정책 안내 페이지 등 주거 탐색부터 안전 계약까지의 주요 사용자 흐름을 일관되게 설계하고 화면으로 구현했습니다.

일부 핵심적인 동적 기능들은 브라우저 로컬 저장소(`localStorage`) 및 가상 데이터(JSON 형식 배열)와 직접 연결되어 있어, 서버/DB 없이도 로그인 상태에 따른 찜하기 목록 연동, 체크리스트 작성 진행률 반영, 1:1 문의글 생성 및 관리자 답변 처리 등 실제 작동 상태를 효과적으로 시연해 볼 수 있는 구조입니다.

## 4. 프로젝트 목표

- **지도와 안전 데이터의 결합**: 매물 위치 중심의 지도 탐색에서 더 나아가 치안시설 및 주의 구간 등 안전 정보를 오버레이로 제공하여 차별화된 주거 안심 탐색 경험 선사
- **전세사기 자가 진단**: 사용자가 임대 계약의 안전성을 쉽게 판단할 수 있도록 단계별 체크리스트와 전세가율 연동형 안전성 검증 도구 제공
- **정보 비대칭성 해소**: 계약 전 확인해야 할 등기부등본 확인 요령 및 전세보증보험, 정부 대출 등의 금융 주거 혜택 정보를 한곳에 집약하여 사회초년생의 의사결정 지원
- **일관되고 편리한 사용자 경험(UX)**: 로그인, 매물 탐색, 안전 진단, 금융 지원 학습, 고객센터 문의까지 하나의 브랜드 톤앤매너로 이어지는 직관적인 인터페이스 구축
- **로컬 스토리지 기반 데모 시연**: 데이터베이스가 연결되어 있지 않은 한계를 보완하기 위해 브라우저 로컬 스토리지를 전방위로 활용하여 상태 보존 및 데이터 제어 흐름 완성
- **반응형 디자인 구현**: PC뿐만 아니라 모바일, 태블릿 등 다양한 해상도와 모바일 환경에 최적화된 반응형 레이아웃 구현

## 5. 기획 의도

대학생이나 자취를 처음 시작하는 청년, 사회초년생들이 주거지를 정할 때 가장 직면하는 문제는 가격과 위치를 넘어선 '주거 환경의 안전성'과 '사기 예방의 막막함'입니다. 기존 부동산 플랫폼들은 거래와 매물 옵션 정보에만 집중되어 있어 사용자가 치안 상태(CCTV, 치안시설)나 사기 위험 정보(체크리스트, 등기부등본 정보)를 파악하려면 경찰청이나 지자체 웹사이트, 법원 등기소 등 여러 분산된 정보원을 일일이 헤매야 하는 큰 불편함이 존재했습니다.

ZipAI는 이러한 실질적인 고민을 해소하기 위해 **"데이터로 찾고, 안전하게 계약하는 플랫폼"**을 기획했습니다. 사용자가 메인 지도 화면에서 맘에 드는 매물의 주변 CCTV 및 범죄 예방 히트맵을 시각적으로 탐색하고, 계약 진행 단계에서는 사기방지 자가진단을 통해 안전 점수를 리포트받으며, 더 나아가 청년용 금융 지원정책을 확인하고 문의하는 체계적인 사용자 여정을 구축하여 실질적인 청년 주거 복지 향상에 기여하고자 하였습니다.

## 7. 주요 구현 기능

### 7.1 메인 매물 검색 및 지도 탐색

- **인터랙티브 지도 연동**: 오픈소스 Leaflet.js 라이브러리를 사용한 유연한 줌/이동 지도 패널 연동
- **매물 데이터 시각화**: 가상의 매물 DB를 지도상에 핀 형태로 매핑하고, 줌 레벨에 따라 행정 구역별(시·도/동 단위) 집계 정보와 개별 마커 전환 표출
- **세부 동적 필터 시스템**: 보증금 범위 슬라이더, 월세 범위 슬라이더, 거래 유형(전세, 월세, 전체), 방유형(원룸, 1.5룸, 투룸, 쓰리룸) 조건 검색 기능
- **부가 옵션 필터**: 주차장 유무, 엘리베이터 설치, 반려동물 가능여부, 안전인증 매물 한정 보기 토글 구현
- **찜하기 및 관심목록**: 매물 리스트 혹은 지도 상세 카드에서 하트 클릭 시 관심 목록에 등록되며, 로컬스토리지를 통해 유지됨. '찜한 매물만 보기' 필터를 활성화하여 선별 가능
- **슬라이드인 상세 패널**: 매물을 클릭하면 가격 정보, 도보 교통 접근성, 보유 옵션, 안심 매물 정보가 담긴 수려한 상세 페이지가 좌측/우측에서 등장

### 7.2 전세사기 안전 진단 (사기방지)

- **계약 주기별 자가진단 체크리스트**: 계약 전 확인, 계약 당일 확인, 잔금 지급 및 입주 시기 확인의 3단계, 12개 주요 위험 항목 점검 양식 제공
- **실시간 프로그레스 바**: 점검 완료 문항에 비례하여 게이지가 가득 차는 시각적 수치 정보 제공
- **종합 안전 진단 리포트 (Safety Report)**: 체크한 내용에 근거하여 안전 점수 도출, 종합 등급(안전 우수/주의/위험) 및 각 질문의 위반 여부에 따른 우선 보완 행동 강령 리포트 동적 렌더링
- **로컬 스토리지 백업**: 작성하던 체크리스트 결과는 자동 보존되어 나중에 사기방지 메인에 리포트로 계속 표시됨

### 7.3 전세가율 계산기

- **깡통전세 판별 연산**: 사용자가 보증금, 매매 시세, 선순위 채권(근저당 등) 금액을 입력하면 나눗셈 연산을 거쳐 실거래가 대비 부채 비율(전세가율)을 %로 산출
- **위험 구간 알림**: 계산 결과 비율이 위험선(예: 80% 이상)을 초과할 시 강한 경고 아이콘과 "깡통전세 위험이 높은 계약입니다." 카드가 동적으로 출력

### 7.4 위험안전도 대시보드 및 안전 지도

- **모의 치안 히트맵**: 서울 마포구 연남동 일대의 가상 치안 데이터를 기반으로 위험 구간(고위험/주의/안전)을 색상 필터로 도식화
- **안전 핀 표시**: 지도상에 CCTV 비상벨, 파출소, 범죄 주의가 필요한 포인트에 커스텀 마커와 아이콘 렌더링
- **지도 유형 전환**: 일반지도 / 위성지도 / 야간 보행 밤길 특화 오버레이 모드를 변경할 수 있는 컨트롤 바 제공
- **6대 세부지표 측정기**: 지역안전, 범죄 주의구간, 여성 밤길, 치안시설, 안전 비상벨, CCTV 밀도를 100점 척도 막대그래프로 세분화하여 도시

### 7.5 로그인 및 회원가입

- **타입별 가입 양식**: 일반 세입자(청년 회원)와 공인중개사 자격 회원 간의 탭 전환 전환 가입
- **실시간 폼 유효성 체크**: 정규식에 어긋나는 아이디/비밀번호 형식 입력 시 시각적인 경고 텍스트 표출
- **데모 회원가입**: 성공적으로 가입 시 로컬 스토리지에 가입 데이터가 저장되며, 이후 로그인 폼에서 해당 아이디/비밀번호 입력 시 정상 로그인 처리 및 상단 메뉴 상태 변화(로그인 -> 마이페이지, 로그아웃)

### 7.6 고객센터 및 관리자 데스크 (CS)

- **FAQ 검색 필터**: 키워드를 입력하면 관련 자주 묻는 질문이 실시간으로 필터링되어 열리는 기능
- **1:1 문의글 저장**: 문의 카테고리, 제목, 이메일, 작성 내용을 입력하여 제출하면 로컬 스토리지에 시간 정보와 함께 보존되며 '나의 문의내역'에 반영
- **관리자 문의 관리 화면 (admin.html)**: 접수된 사용자의 1:1 문의 내용을 표 형태로 받아온 뒤, 개별 항목에 마우스를 대어 답변을 작성하여 상태를 '답변완료'로 수정하거나 삭제할 수 있는 백오피스 데모 제공

### 7.7 주거 금융 지원관 (금융지원정책)

- **4대 청년 밀착형 정책 상세관**: 보증보험 가입 요령, 버팀목 대출 가이드, 청년 주거 금융 지원, 청년 월세 20만원 지원 등 까다롭고 누락하기 쉬운 정책 요건과 절차를 카드식 화면과 표로 알기 쉽게 설계

## 9. 기술 스택

### Frontend

- **HTML5**: 웹 접근성(WAI-ARIA)을 준수하고 브라우저 검색을 최적화하기 위한 시맨틱 구조 마크업 설계
- **CSS3**: Flexbox 및 Grid 기반 반응형 구조 설계, CSS custom properties(변수)를 적용한 디자인 시스템(Color, Typography, Border) 표준화 및 애니메이션 처리
- **JavaScript (ES6+)**: Vanilla JS 중심의 DOM 컨트롤, 폼 값 검증, 브라우저 로컬 저장소 상호작용 제어
- **Leaflet.js API**: 지도 패널 구동, 커스텀 마커 설계, 다각형 폴리곤을 활용한 위험안전구역 오버레이 오퍼레이션
- **Font Awesome & Bootstrap 5 Icons**: 사용자 친화적인 메뉴 아이콘 및 상태 지표 이미지 구성
- **Google Fonts**: 고가독성의 국문 서체 `Noto Sans KR` 및 제목용 서체 `IBM Plex Sans KR` 탑재

### Backend / Infrastructure (데모 한정)

- **Web Storage API (localStorage)**: 데이터베이스 및 API 서버를 대체해 로컬 브라우저 세션에 회원 가입 내역, 찜 정보, 자가 진단 보고서 데이터, 1:1 문의 적재 사항 보존
- **JSON**: 매물 정보, 옵션, 위치 정보를 담은 로컬 가상 객체 데이터 구조 설계

### Collaboration & Deployment

- **Git / GitHub**: 버전 관리 및 기능 단위 브랜치 협업
- **GitHub Pages**: 정적 프론트엔드 환경 호스팅 및 웹 클라이언트 데모 배포

## 11. 실행 방법

### 11.1 저장소 복제

```bash
git clone https://github.com/tylyoon/zipai.git
cd zipai
```

### 11.2 웹 클라이언트 로컬 실행

본 프로젝트는 데이터가 클라이언트에 내장된 순수 프론트엔드 환경으로 구성되어 있어, 별도의 설치나 빌드 과정 없이 아래의 방법 중 하나로 즉시 기동하여 실행할 수 있습니다.

- **방법 1: 직접 열기**

  - 클론 받은 폴더 내의 `index.html` 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge 등)로 끌어다 놓아(Drag & Drop) 즉시 실행합니다.
- **방법 2: VS Code Live Server 이용 (권장)**

  - VS Code에서 `zipai` 폴더를 열고 `Live Server` 확장을 설치한 후, 하단의 `Go Live`를 클릭하여 `http://127.0.0.1:5500` 로컬 웹 서버 환경에서 접속합니다.
- **방법 3: Python 정적 서버 이용**

  - 터미널(Command Prompt, Terminal)에서 프로젝트 폴더로 이동한 뒤 아래 명령을 구동합니다.
    ```bash
    python -m http.server 8000
    ```
  - 브라우저를 열고 `http://localhost:8000`에 접속합니다.

## 13. 추가 구현이 필요한 기능

- **매물 등록 페이지**: 일반 회원이나 공인중개사가 자신의 안전 보증 매물을 4단계(기본정보 -> 권리관계 -> 사진 -> 승인대기) 양식을 통해 등록할 수 있는 전용 폼 페이지 추가
- **실시간 지도 영역 재검색**: 사용자가 지도를 이동하거나 축소/확대할 때 맵 뷰포트 영역의 경위도 범위(Bounds)에 위치하는 매물을 동적으로 필터링하여 리스트업하는 기능 고도화
- **실제 등기부등본 OCR 자동 인식**: 등기부등본 PDF나 사진을 업로드하면 광학 문자 인식(OCR)을 통해 갑구의 소유주 이름과 을구의 근저당 및 가압류 현황을 추출하여 전세가율 위험도를 자동으로 입력해 주는 기능
- **AI 맞춤형 안심 지역 추천 챗봇**: 사용자의 선호 거주지, 직장 주소, 예산, 필수 조건 등을 자연어로 물어보면 조건에 가장 부합하는 서울 시내 행정동 및 세부 매물을 AI 추천 리포트와 함께 제안해 주는 기능
- **실제 회원 데이터베이스 및 백엔드 서버**: 이메일 가입인증, 보안 비밀번호 해싱 처리, 세션 또는 JWT 토큰을 활용한 정상적인 유저 권한 인프라와 MySQL 매물 관계 데이터베이스 연동

## 14. 개선 및 보완 사항

### 14.1 CSS 구조 통합 및 파일 중복 제거

- 각 페이지 단위로 개별 제작된 헤더, 푸터, 레이아웃 CSS(header.css, footer.css)의 중복 코드를 완벽히 정제하고 공용 컴포넌트 스타일로 정합
- CSS 커스텀 변수(`--zipai-primary`, `--zipai-navy` 등)의 스타일링 토큰을 단일 `common.css`에서 완벽히 바인딩하여 전 페이지의 일관성 있는 색상 정렬 및 라이트/다크 테마 확장 대응력 강화

### 14.2 상대 경로 및 절대 경로 유효성 통일

- 메인 `index.html`과 하위 폴더인 `templates/`에 위치한 페이지 간의 헤더 링크 이동 시 로컬 호스트와 GitHub Pages 서브 도메인 환경 모두에서 이동이 부드럽게 흐르도록 `href` 상대 주소 체계 점검
- 로그인하지 않은 사용자가 마이페이지나 1:1 문의 등 회원 등급 권한이 필요한 페이지에 진입을 시도할 때 강제로 `login.html`로 튕겨내고 경고창을 제공하는 미들웨어 격 기능 보강

## 3. 프로젝트 개요

**ZipAI(집아이)**는 청년 및 사회초년생이 안전한 주거를 선택할 수 있도록 지원하는 **AI 기반 청년 주거 안전 플랫폼**입니다. 직방·다방과 같은 기존의 매물 탐색 플랫폼 모델을 바탕으로, 계약 시 반드시 확인해야 하는 전세사기 위험 정보와 지역별 안전 치안 데이터(CCTV, 비상벨, 경찰서 분포 등)를 시각화하여 사용자가 한눈에 안전도를 분석할 수 있도록 개발했습니다.

현재 프로젝트는 HTML, CSS, JavaScript 중심의 프론트엔드 프로토타입으로 이루어져 있으며, Leaflet.js 기반의 매물 탐색 지도, 위험안전도 히트맵 분석 페이지, 전세사기 예방 체크리스트 및 실시간 전세가율 계산기, 회원인증(로그인·회원가입) 및 마이페이지, 고객센터(FAQ 및 1:1 문의), 관리자 문의 제어 대시보드, 청년 맞춤형 금융지원정책 안내 페이지 등 주거 탐색부터 안전 계약까지의 주요 사용자 흐름을 일관되게 설계하고 화면으로 구현했습니다.

일부 핵심적인 동적 기능들은 브라우저 로컬 저장소(`localStorage`) 및 가상 데이터(JSON 형식 배열)와 직접 연결되어 있어, 서버/DB 없이도 로그인 상태에 따른 찜하기 목록 연동, 체크리스트 작성 진행률 반영, 1:1 문의글 생성 및 관리자 답변 처리 등 실제 작동 상태를 효과적으로 시연해 볼 수 있는 구조입니다.

## 7. 주요 구현 기능

### 7.1 메인 매물 검색 및 지도 탐색

- **인터랙티브 지도 연동**: 오픈소스 Leaflet.js 라이브러리를 사용한 유연한 줌/이동 지도 패널 연동
- **매물 데이터 시각화**: 가상의 매물 DB를 지도상에 핀 형태로 매핑하고, 줌 레벨에 따라 행정 구역별(시·도/동 단위) 집계 정보와 개별 마커 전환 표출
- **세부 동적 필터 시스템**: 보증금 범위 슬라이더, 월세 범위 슬라이더, 거래 유형(전세, 월세, 전체), 방유형(원룸, 1.5룸, 투룸, 쓰리룸) 조건 검색 기능
- **부가 옵션 필터**: 주차장 유무, 엘리베이터 설치, 반려동물 가능여부, 안전인증 매물 한정 보기 토글 구현
- **찜하기 및 관심목록**: 매물 리스트 혹은 지도 상세 카드에서 하트 클릭 시 관심 목록에 등록되며, 로컬스토리지를 통해 유지됨. '찜한 매물만 보기' 필터를 활성화하여 선별 가능
- **슬라이드인 상세 패널**: 매물을 클릭하면 가격 정보, 도보 교통 접근성, 보유 옵션, 안심 매물 정보가 담긴 수려한 상세 페이지가 좌측/우측에서 등장

### 7.2 전세사기 안전 진단 (사기방지)

- **계약 주기별 자가진단 체크리스트**: 계약 전 확인, 계약 당일 확인, 잔금 지급 및 입주 시기 확인의 3단계, 12개 주요 위험 항목 점검 양식 제공
- **실시간 프로그레스 바**: 점검 완료 문항에 비례하여 게이지가 가득 차는 시각적 수치 정보 제공
- **종합 안전 진단 리포트 (Safety Report)**: 체크한 내용에 근거하여 안전 점수 도출, 종합 등급(안전 우수/주의/위험) 및 각 질문의 위반 여부에 따른 우선 보완 행동 강령 리포트 동적 렌더링
- **로컬 스토리지 백업**: 작성하던 체크리스트 결과는 자동 보존되어 나중에 사기방지 메인에 리포트로 계속 표시됨

### 7.3 전세가율 계산기

- **깡통전세 판별 연산**: 사용자가 보증금, 매매 시세, 선순위 채권(근저당 등) 금액을 입력하면 나눗셈 연산을 거쳐 실거래가 대비 부채 비율(전세가율)을 %로 산출
- **위험 구간 알림**: 계산 결과 비율이 위험선(예: 80% 이상)을 초과할 시 강한 경고 아이콘과 "깡통전세 위험이 높은 계약입니다." 카드가 동적으로 출력

### 7.4 위험안전도 대시보드 및 안전 지도

- **모의 치안 히트맵**: 서울 마포구 연남동 일대의 가상 치안 데이터를 기반으로 위험 구간(고위험/주의/안전)을 색상 필터로 도식화
- **안전 핀 표시**: 지도상에 CCTV 비상벨, 파출소, 범죄 주의가 필요한 포인트에 커스텀 마커와 아이콘 렌더링
- **지도 유형 전환**: 일반지도 / 위성지도 / 야간 보행 밤길 특화 오버레이 모드를 변경할 수 있는 컨트롤 바 제공
- **6대 세부지표 측정기**: 지역안전, 범죄 주의구간, 여성 밤길, 치안시설, 안전 비상벨, CCTV 밀도를 100점 척도 막대그래프로 세분화하여 도시

### 7.5 로그인 및 회원가입

- **타입별 가입 양식**: 일반 세입자(청년 회원)와 공인중개사 자격 회원 간의 탭 전환 전환 가입
- **실시간 폼 유효성 체크**: 정규식에 어긋나는 아이디/비밀번호 형식 입력 시 시각적인 경고 텍스트 표출
- **데모 회원가입**: 성공적으로 가입 시 로컬 스토리지에 가입 데이터가 저장되며, 이후 로그인 폼에서 해당 아이디/비밀번호 입력 시 정상 로그인 처리 및 상단 메뉴 상태 변화(로그인 -> 마이페이지, 로그아웃)

### 7.6 고객센터 및 관리자 데스크 (CS)

- **FAQ 검색 필터**: 키워드를 입력하면 관련 자주 묻는 질문이 실시간으로 필터링되어 열리는 기능
- **1:1 문의글 저장**: 문의 카테고리, 제목, 이메일, 작성 내용을 입력하여 제출하면 로컬 스토리지에 시간 정보와 함께 보존되며 '나의 문의내역'에 반영
- **관리자 문의 관리 화면 (admin.html)**: 접수된 사용자의 1:1 문의 내용을 표 형태로 받아온 뒤, 개별 항목에 마우스를 대어 답변을 작성하여 상태를 '답변완료'로 수정하거나 삭제할 수 있는 백오피스 데모 제공

### 7.7 주거 금융 지원관 (금융지원정책)

- **4대 청년 밀착형 정책 상세관**: 보증보험 가입 요령, 버팀목 대출 가이드, 청년 주거 금융 지원, 청년 월세 20만원 지원 등 까다롭고 누락하기 쉬운 정책 요건과 절차를 카드식 화면과 표로 알기 쉽게 설계

## 9. 기술 스택

### Frontend

- **HTML5**: 웹 접근성(WAI-ARIA)을 준수하고 브라우저 검색을 최적화하기 위한 시맨틱 구조 마크업 설계
- **CSS3**: Flexbox 및 Grid 기반 반응형 구조 설계, CSS custom properties(변수)를 적용한 디자인 시스템(Color, Typography, Border) 표준화 및 애니메이션 처리
- **JavaScript (ES6+)**: Vanilla JS 중심의 DOM 컨트롤, 폼 값 검증, 브라우저 로컬 저장소 상호작용 제어
- **Leaflet.js API**: 지도 패널 구동, 커스텀 마커 설계, 다각형 폴리곤을 활용한 위험안전구역 오버레이 오퍼레이션
- **Font Awesome & Bootstrap 5 Icons**: 사용자 친화적인 메뉴 아이콘 및 상태 지표 이미지 구성
- **Google Fonts**: 고가독성의 국문 서체 `Noto Sans KR` 및 제목용 서체 `IBM Plex Sans KR` 탑재

### Backend / Infrastructure (데모 한정)

- **Web Storage API (localStorage)**: 데이터베이스 및 API 서버를 대체해 로컬 브라우저 세션에 회원 가입 내역, 찜 정보, 자가 진단 보고서 데이터, 1:1 문의 적재 사항 보존
- **JSON**: 매물 정보, 옵션, 위치 정보를 담은 로컬 가상 객체 데이터 구조 설계

### Collaboration & Deployment

- **Git / GitHub**: 버전 관리 및 기능 단위 브랜치 협업
- **GitHub Pages**: 정적 프론트엔드 환경 호스팅 및 웹 클라이언트 데모 배포

## 11. 실행 방법

### 11.1 저장소 복제

```bash
git clone https://github.com/tylyoon/zipai.git
cd zipai
```

### 11.2 웹 클라이언트 로컬 실행

본 프로젝트는 데이터가 클라이언트에 내장된 순수 프론트엔드 환경으로 구성되어 있어, 별도의 설치나 빌드 과정 없이 아래의 방법 중 하나로 즉시 기동하여 실행할 수 있습니다.

- **방법 1: 직접 열기**

  - 클론 받은 폴더 내의 `index.html` 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge 등)로 끌어다 놓아(Drag & Drop) 즉시 실행합니다.
- **방법 2: VS Code Live Server 이용 (권장)**

  - VS Code에서 `zipai` 폴더를 열고 `Live Server` 확장을 설치한 후, 하단의 `Go Live`를 클릭하여 `http://127.0.0.1:5500` 로컬 웹 서버 환경에서 접속합니다.
- **방법 3: Python 정적 서버 이용**

  - 터미널(Command Prompt, Terminal)에서 프로젝트 폴더로 이동한 뒤 아래 명령을 구동합니다.
    ```bash
    python -m http.server 8000
    ```
  - 브라우저를 열고 `http://localhost:8000`에 접속합니다.

## 13. 추가 구현이 필요한 기능

- **실시간 지도 영역 재검색**: 사용자가 지도를 이동하거나 축소/확대할 때 맵 뷰포트 영역의 경위도 범위(Bounds)에 위치하는 매물을 동적으로 필터링하여 리스트업하는 기능 고도화
- **실제 등기부등본 OCR 자동 인식**: 등기부등본 PDF나 사진을 업로드하면 광학 문자 인식(OCR)을 통해 갑구의 소유주 이름과 을구의 근저당 및 가압류 현황을 추출하여 전세가율 위험도를 자동으로 입력해 주는 기능
- **AI 맞춤형 안심 지역 추천 챗봇**: 사용자의 선호 거주지, 직장 주소, 예산, 필수 조건 등을 자연어로 물어보면 조건에 가장 부합하는 서울 시내 행정동 및 세부 매물을 AI 추천 리포트와 함께 제안해 주는 기능
- **실제 회원 데이터베이스 및 백엔드 서버**: 이메일 가입인증, 보안 비밀번호 해싱 처리, 세션 또는 JWT 토큰을 활용한 정상적인 유저 권한 인프라와 MySQL 매물 관계 데이터베이스 연동

## 3. 프로젝트 개요

**ZipAI(집아이)**는 청년 및 사회초년생이 안전한 주거를 선택할 수 있도록 지원하는 **AI 기반 청년 주거 안전 플랫폼**입니다. 직방·다방과 같은 기존의 매물 탐색 플랫폼 모델을 바탕으로, 계약 시 반드시 확인해야 하는 전세사기 위험 정보와 지역별 안전 치안 데이터(CCTV, 비상벨, 경찰서 분포 등)를 시각화하여 사용자가 한눈에 안전도를 분석할 수 있도록 개발했습니다.

현재 프로젝트는 HTML, CSS, JavaScript 중심의 프론트엔드 프로토타입으로 이루어져 있으며, Leaflet.js 기반의 매물 탐색 지도, 위험안전도 히트맵 분석 페이지, 전세사기 예방 체크리스트 및 실시간 전세가율 계산기, 회원인증(로그인·회원가입) 및 마이페이지, 고객센터(FAQ 및 1:1 문의), 관리자 문의 제어 대시보드, 청년 맞춤형 금융지원정책 안내 페이지 등 주거 탐색부터 안전 계약까지의 주요 사용자 흐름을 일관되게 설계하고 화면으로 구현했습니다.

일부 핵심적인 동적 기능들은 브라우저 로컬 저장소(`localStorage`) 및 가상 데이터(JSON 형식 배열)와 직접 연결되어 있어, 서버/DB 없이도 로그인 상태에 따른 찜하기 목록 연동, 체크리스트 작성 진행률 반영, 1:1 문의글 생성 및 관리자 답변 처리 등 실제 작동 상태를 효과적으로 시연해 볼 수 있는 구조입니다.

## 4. 프로젝트 목표

- **지도와 안전 데이터의 결합**: 매물 위치 중심의 지도 탐색에서 더 나아가 치안시설 및 주의 구간 등 안전 정보를 오버레이로 제공하여 차별화된 주거 안심 탐색 경험 선사
- **전세사기 자가 진단**: 사용자가 임대 계약의 안전성을 쉽게 판단할 수 있도록 단계별 체크리스트와 전세가율 연동형 안전성 검증 도구 제공
- **정보 비대칭성 해소**: 계약 전 확인해야 할 등기부등본 확인 요령 및 전세보증보험, 정부 대출 등의 금융 주거 혜택 정보를 한곳에 집약하여 사회초년생의 의사결정 지원
- **일관되고 편리한 사용자 경험(UX)**: 로그인, 매물 탐색, 안전 진단, 금융 지원 학습, 고객센터 문의까지 하나의 브랜드 톤앤매너로 이어지는 직관적인 인터페이스 구축
- **로컬 스토리지 기반 데모 시연**: 데이터베이스가 연결되어 있지 않은 한계를 보완하기 위해 브라우저 로컬 스토리지를 전방위로 활용하여 상태 보존 및 데이터 제어 흐름 완성
- **반응형 디자인 구현**: PC뿐만 아니라 모바일, 태블릿 등 다양한 해상도와 모바일 환경에 최적화된 반응형 레이아웃 구현

## 5. 기획 의도

대학생이나 자취를 처음 시작하는 청년, 사회초년생들이 주거지를 정할 때 가장 직면하는 문제는 가격과 위치를 넘어선 '주거 환경의 안전성'과 '사기 예방의 막막함'입니다. 기존 부동산 플랫폼들은 거래와 매물 옵션 정보에만 집중되어 있어 사용자가 치안 상태(CCTV, 치안시설)나 사기 위험 정보(체크리스트, 등기부등본 정보)를 파악하려면 경찰청이나 지자체 웹사이트, 법원 등기소 등 여러 분산된 정보원을 일일이 헤매야 하는 큰 불편함이 존재했습니다.

ZipAI는 이러한 실질적인 고민을 해소하기 위해 **"데이터로 찾고, 안전하게 계약하는 플랫폼"**을 기획했습니다. 사용자가 메인 지도 화면에서 맘에 드는 매물의 주변 CCTV 및 범죄 예방 히트맵을 시각적으로 탐색하고, 계약 진행 단계에서는 사기방지 자가진단을 통해 안전 점수를 리포트받으며, 더 나아가 청년용 금융 지원정책을 확인하고 문의하는 체계적인 사용자 여정을 구축하여 실질적인 청년 주거 복지 향상에 기여하고자 하였습니다.

## 7. 주요 구현 기능

### 7.1 메인 매물 검색 및 지도 탐색

- **인터랙티브 지도 연동**: 오픈소스 Leaflet.js 라이브러리를 사용한 유연한 줌/이동 지도 패널 연동
- **매물 데이터 시각화**: 가상의 매물 DB를 지도상에 핀 형태로 매핑하고, 줌 레벨에 따라 행정 구역별(시·도/동 단위) 집계 정보와 개별 마커 전환 표출
- **세부 동적 필터 시스템**: 보증금 범위 슬라이더, 월세 범위 슬라이더, 거래 유형(전세, 월세, 전체), 방유형(원룸, 1.5룸, 투룸, 쓰리룸) 조건 검색 기능
- **부가 옵션 필터**: 주차장 유무, 엘리베이터 설치, 반려동물 가능여부, 안전인증 매물 한정 보기 토글 구현
- **찜하기 및 관심목록**: 매물 리스트 혹은 지도 상세 카드에서 하트 클릭 시 관심 목록에 등록되며, 로컬스토리지를 통해 유지됨. '찜한 매물만 보기' 필터를 활성화하여 선별 가능
- **슬라이드인 상세 패널**: 매물을 클릭하면 가격 정보, 도보 교통 접근성, 보유 옵션, 안심 매물 정보가 담긴 수려한 상세 페이지가 좌측/우측에서 등장

### 7.2 전세사기 안전 진단 (사기방지)

- **계약 주기별 자가진단 체크리스트**: 계약 전 확인, 계약 당일 확인, 잔금 지급 및 입주 시기 확인의 3단계, 12개 주요 위험 항목 점검 양식 제공
- **실시간 프로그레스 바**: 점검 완료 문항에 비례하여 게이지가 가득 차는 시각적 수치 정보 제공
- **종합 안전 진단 리포트 (Safety Report)**: 체크한 내용에 근거하여 안전 점수 도출, 종합 등급(안전 우수/주의/위험) 및 각 질문의 위반 여부에 따른 우선 보완 행동 강령 리포트 동적 렌더링
- **로컬 스토리지 백업**: 작성하던 체크리스트 결과는 자동 보존되어 나중에 사기방지 메인에 리포트로 계속 표시됨

### 7.3 전세가율 계산기

- **깡통전세 판별 연산**: 사용자가 보증금, 매매 시세, 선순위 채권(근저당 등) 금액을 입력하면 나눗셈 연산을 거쳐 실거래가 대비 부채 비율(전세가율)을 %로 산출
- **위험 구간 알림**: 계산 결과 비율이 위험선(예: 80% 이상)을 초과할 시 강한 경고 아이콘과 "깡통전세 위험이 높은 계약입니다." 카드가 동적으로 출력

### 7.4 위험안전도 대시보드 및 안전 지도

- **모의 치안 히트맵**: 서울 마포구 연남동 일대의 가상 치안 데이터를 기반으로 위험 구간(고위험/주의/안전)을 색상 필터로 도식화
- **안전 핀 표시**: 지도상에 CCTV 비상벨, 파출소, 범죄 주의가 필요한 포인트에 커스텀 마커와 아이콘 렌더링
- **지도 유형 전환**: 일반지도 / 위성지도 / 야간 보행 밤길 특화 오버레이 모드를 변경할 수 있는 컨트롤 바 제공
- **6대 세부지표 측정기**: 지역안전, 범죄 주의구간, 여성 밤길, 치안시설, 안전 비상벨, CCTV 밀도를 100점 척도 막대그래프로 세분화하여 도시

### 7.5 로그인 및 회원가입

- **타입별 가입 양식**: 일반 세입자(청년 회원)와 공인중개사 자격 회원 간의 탭 전환 전환 가입
- **실시간 폼 유효성 체크**: 정규식에 어긋나는 아이디/비밀번호 형식 입력 시 시각적인 경고 텍스트 표출
- **데모 회원가입**: 성공적으로 가입 시 로컬 스토리지에 가입 데이터가 저장되며, 이후 로그인 폼에서 해당 아이디/비밀번호 입력 시 정상 로그인 처리 및 상단 메뉴 상태 변화(로그인 -> 마이페이지, 로그아웃)

### 7.6 고객센터 및 관리자 데스크 (CS)

- **FAQ 검색 필터**: 키워드를 입력하면 관련 자주 묻는 질문이 실시간으로 필터링되어 열리는 기능
- **1:1 문의글 저장**: 문의 카테고리, 제목, 이메일, 작성 내용을 입력하여 제출하면 로컬 스토리지에 시간 정보와 함께 보존되며 '나의 문의내역'에 반영
- **관리자 문의 관리 화면 (admin.html)**: 접수된 사용자의 1:1 문의 내용을 표 형태로 받아온 뒤, 개별 항목에 마우스를 대어 답변을 작성하여 상태를 '답변완료'로 수정하거나 삭제할 수 있는 백오피스 데모 제공

### 7.7 주거 금융 지원관 (금융지원정책)

- **4대 청년 밀착형 정책 상세관**: 보증보험 가입 요령, 버팀목 대출 가이드, 청년 주거 금융 지원, 청년 월세 20만원 지원 등 까다롭고 누락하기 쉬운 정책 요건과 절차를 카드식 화면과 표로 알기 쉽게 설계

## 9. 기술 스택

### Frontend

- **HTML5**: 웹 접근성(WAI-ARIA)을 준수하고 브라우저 검색을 최적화하기 위한 시맨틱 구조 마크업 설계
- **CSS3**: Flexbox 및 Grid 기반 반응형 구조 설계, CSS custom properties(변수)를 적용한 디자인 시스템(Color, Typography, Border) 표준화 및 애니메이션 처리
- **JavaScript (ES6+)**: Vanilla JS 중심의 DOM 컨트롤, 폼 값 검증, 브라우저 로컬 저장소 상호작용 제어
- **Leaflet.js API**: 지도 패널 구동, 커스텀 마커 설계, 다각형 폴리곤을 활용한 위험안전구역 오버레이 오퍼레이션
- **Font Awesome & Bootstrap 5 Icons**: 사용자 친화적인 메뉴 아이콘 및 상태 지표 이미지 구성
- **Google Fonts**: 고가독성의 국문 서체 `Noto Sans KR` 및 제목용 서체 `IBM Plex Sans KR` 탑재

### Backend / Infrastructure (데모 한정)

- **Web Storage API (localStorage)**: 데이터베이스 및 API 서버를 대체해 로컬 브라우저 세션에 회원 가입 내역, 찜 정보, 자가 진단 보고서 데이터, 1:1 문의 적재 사항 보존

## 11. 실행 방법

### 11.1 저장소 복제

```bash
git clone https://github.com/tylyoon/zipai.git
cd zipai
```

### 11.2 웹 클라이언트 로컬 실행

본 프로젝트는 데이터가 클라이언트에 내장된 순수 프론트엔드 환경으로 구성되어 있어, 별도의 설치나 빌드 과정 없이 아래의 방법 중 하나로 즉시 기동하여 실행할 수 있습니다.

- **방법 1: 직접 열기**

  - 클론 받은 폴더 내의 `index.html` 파일을 더블클릭하거나 웹 브라우저(Chrome, Edge 등)로 끌어다 놓아(Drag & Drop) 즉시 실행합니다.
- **방법 2: VS Code Live Server 이용 (권장)**

  - VS Code에서 `zipai` 폴더를 열고 `Live Server` 확장을 설치한 후, 하단의 `Go Live`를 클릭하여 `http://127.0.0.1:5500` 로컬 웹 서버 환경에서 접속합니다.
- **방법 3: Python 정적 서버 이용**

  - 터미널(Command Prompt, Terminal)에서 프로젝트 폴더로 이동한 뒤 아래 명령을 구동합니다.
    ```bash
    python -m http.server 8000
    ```
  - 브라우저를 열고 `http://localhost:8000`에 접속합니다.

## 13. 추가 구현이 필요한 기능

- **매물 등록 페이지**: 일반 회원이나 공인중개사가 자신의 안전 보증 매물을 4단계(기본정보 -> 권리관계 -> 사진 -> 승인대기) 양식을 통해 등록할 수 있는 전용 폼 페이지 추가
- **실시간 지도 영역 재검색**: 사용자가 지도를 이동하거나 축소/확대할 때 맵 뷰포트 영역의 경위도 범위(Bounds)에 위치하는 매물을 동적으로 필터링하여 리스트업하는 기능 고도화
- **실제 등기부등본 OCR 자동 인식**: 등기부등본 PDF나 사진을 업로드하면 광학 문자 인식(OCR)을 통해 갑구의 소유주 이름과 을구의 근저당 및 가압류 현황을 추출하여 전세가율 위험도를 자동으로 입력해 주는 기능
- **AI 맞춤형 안심 지역 추천 챗봇**: 사용자의 선호 거주지, 직장 주소, 예산, 필수 조건 등을 자연어로 물어보면 조건에 가장 부합하는 서울 시내 행정동 및 세부 매물을 AI 추천 리포트와 함께 제안해 주는 기능
- **실제 회원 데이터베이스 및 백엔드 서버**: 이메일 가입인증, 보안 비밀번호 해싱 처리, 세션 또는 JWT 토큰을 활용한 정상적인 유저 권한 인프라와 MySQL 매물 관계 데이터베이스 연동

## 14. 개선 및 보완 사항

### 14.1 CSS 구조 통합 및 파일 중복 제거

- 각 페이지 단위로 개별 제작된 헤더, 푸터, 레이아웃 CSS(header.css, footer.css)의 중복 코드를 완벽히 정제하고 공용 컴포넌트 스타일로 정합
- CSS 커스텀 변수(`--zipai-primary`, `--zipai-navy` 등)의 스타일링 토큰을 단일 `common.css`에서 완벽히 바인딩하여 전 페이지의 일관성 있는 색상 정렬 및 라이트/다크 테마 확장 대응력 강화

### 14.2 상대 경로 및 절대 경로 유효성 통일

- 메인 `index.html`과 하위 폴더인 `templates/`에 위치한 페이지 간의 헤더 링크 이동 시 로컬 호스트와 GitHub Pages 서브 도메인 환경 모두에서 이동이 부드럽게 흐르도록 `href` 상대 주소 체계 점검
- 로그인하지 않은 사용자가 마이페이지나 1:1 문의 등 회원 등급 권한이 필요한 페이지에 진입을 시도할 때 강제로 `login.html`로 튕겨내고 경고창을 제공하는 미들웨어 격 기능 보강

### 14.3 예외 상황 처리 및 입력 오류 알림 고도화

- 회원가입 시 아이디 중복 검사 로직(로컬스토리지에 기 가입된 아이디가 존재하는지 체크) 추가 및 에러가 있는 필드로의 자동 포커스(Focus) 처리
- 전세가율 계산기에서 0이나 음수 값, 텍스트가 입력되었을 때 예외 처리를 수행하여 계산 오작동 및 `NaN` 출력 방지 처리 강화

## 15. 향후 발전 방향

- **개인 맞춤형 동적 AI 리포트**: 국토교통부 실거래 정보와 생활안전 빅데이터를 기반으로, AI가 주변 매물 가격 상승 추이 및 이 지역의 치안 동향 분석 문장을 자동 생성해 주는 서비스
- **PWA (Progressive Web App) 도입**: 모바일 디바이스에서 독립형 앱처럼 구동되고, 푸시 알림을 통해 찜한 매물의 가격 변동 및 주변 관심지역의 치안 등급 변경 즉시 알림 제공
- **부동산 전문가/중개사 1:1 상담 매칭**: 계약 위험도가 높게(예: 주의/위험군) 판별된 매물의 보고서를 중개사나 안전 대리인에게 즉시 전송하여 전세사기 예방 실시간 온라인 전문 피드백 기능 개설
