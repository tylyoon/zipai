# ZipAI: AI 기반 청년 주거 안전 플랫폼

**데모 페이지:** https://zipai2026.netlify.app/

---

## 프로젝트 소개

**ZipAI(집아이)**는 청년 및 사회초년생이 안전한 주거를 선택할 수 있도록 지원하는 **AI 기반 청년 주거 안전 플랫폼**입니다. 직방·다방과 같은 매물 탐색 모델을 바탕으로, 전세사기 위험 정보와 지역별 치안 데이터(CCTV, 비상벨, 경찰서 분포 등)를 시각화하여 사용자가 한눈에 안전도를 분석할 수 있습니다.

HTML·CSS·JavaScript 중심의 프론트엔드 프로토타입으로, Leaflet.js 기반 매물 지도, 위험안전도 히트맵, 전세사기 예방 체크리스트·전세가율 계산기, 회원 인증·마이페이지, 고객센터, 관리자 대시보드, 청년 금융지원정책 안내, LH·공공임대 연동, 행복주택 안내 등 주거 탐색부터 안전 계약까지의 사용자 흐름을 구현했습니다.

일부 동적 기능은 `localStorage` 및 가상 JSON 데이터와 연결되어 서버/DB 없이도 찜하기, 체크리스트 진행률, 1:1 문의·관리자 답변 등을 시연할 수 있습니다. Node.js 서버와 Spring Boot 백엔드(Aiven MySQL) 연동을 통해 Excel 매물, LH 공공데이터 API, 회원·매물·문의 등 실서비스 기능도 확장 중입니다.

---

## 프로젝트 목표

- **지도와 안전 데이터 결합**: 매물 위치 탐색에 치안시설·주의 구간 등 안전 정보를 오버레이로 제공
- **전세사기 자가 진단**: 단계별 체크리스트와 전세가율 연동형 안전성 검증 도구 제공
- **정보 비대칭 해소**: 등기부 확인 요령, 전세보증보험·정부 대출 등 금융 혜택 정보를 한곳에 집약
- **일관된 UX**: 로그인부터 매물 탐색, 안전 진단, 금융 지원, 고객센터까지 통일된 인터페이스 구축
- **반응형 디자인**: PC·태블릿·모바일 등 다양한 해상도에 최적화된 레이아웃 구현

## 기획 의도

대학생·사회초년생이 주거지를 정할 때 가격과 위치를 넘어선 **주거 환경의 안전성**과 **사기 예방의 막막함**이 핵심 과제입니다. 기존 부동산 플랫폼은 거래·매물 정보에 집중되어, 치안 상태나 사기 위험 정보를 확인하려면 경찰청·지자체·등기소 등 여러 출처를 직접 찾아야 합니다.

ZipAI는 **"데이터로 찾고, 안전하게 계약하는 플랫폼"**을 목표로 기획했습니다. 지도에서 CCTV·히트맵을 탐색하고, 계약 단계에서 사기방지 자가진단을 받으며, 청년 금융 지원정책을 확인하는 체계적인 사용자 여정을 통해 청년 주거 복지 향상에 기여하고자 합니다.

## 기술 스택

### Frontend

- **HTML5** · **CSS3** · **JavaScript (ES6+)**: Vanilla JS 기반 DOM 제어, 폼 검증, 반응형 레이아웃(Flexbox/Grid)
- **Leaflet.js**: 지도 패널, 커스텀 마커, 위험구역 폴리곤 오버레이
- **Font Awesome & Bootstrap 5 Icons** · **Google Fonts** (`Noto Sans KR`, `IBM Plex Sans KR`)
- **CSS Custom Properties**: 디자인 토큰 기반 색상·타이포그래피 표준화

### Backend / Infrastructure

- **Node.js**: 정적 파일 제공, Excel 매물 변환, LH 공공데이터 API 중계
- **Java 21 · Spring Boot 3.5.4**: REST API, JPA, Flyway 마이그레이션
- **MySQL 8.4 (Aiven)**: 회원·매물·찜·문의·커뮤니티 등 영속 데이터
- **Web Storage API (`localStorage`)**: 데모용 세션·찜·체크리스트·문의 데이터
- **Netlify** (프론트) · **Render** (백엔드) · **GitHub Pages** (정적 데모)

### Collaboration

- **Git / GitHub** · **GitHub Actions** · **Docker**

## UI 핵심 설계

### 매물 탐색 (메인)

- Leaflet.js 기반 인터랙티브 지도, 줌 레벨별 행정동 집계·개별 마커 전환
- 일반 전·월세 / LH·공공임대 카테고리 분리, 경기도 31개 시·군 기준 검색
- 보증금·월세 슬라이더, 거래 유형·방 유형·부가 옵션(주차, 엘리베이터, 반려동물) 필터
- 슬라이드인 상세 패널, 찜하기(하트) 및 `localStorage` 연동, 매물 등록 모달

### 사기방지 · 계약 안전

- 3단계(계약 전·당일·입주) 12항목 체크리스트 + 실시간 프로그레스 바
- 종합 안전 진단 리포트(점수·등급·보완 행동 가이드)
- 전세가율 계산기(보증금·매매가·근저당 입력 → 위험 등급 카드)
- 계약 시기별 등기부 해독 아코디언 가이드

### 위험안전도

- CCTV·비상벨·파출소·범죄주의구간 커스텀 마커 및 히트맵
- 일반/위성/야간 보행 오버레이 전환, 6대 세부지표(100점 막대그래프) 대시보드
- 주소·지역 검색 기반 종합 안전도 분석 화면

### 금융지원 · 행복주택

- 4대 청년 금융정책(보증보험, 버팀목, 주거금융, 월세 지원) 카드형 안내
- 대상·목적별 맞춤 대출 추천 필터, 대출 한도·금리·상환 스케줄 계산기
- 행복주택 특징·신청 절차 안내, 신청자격 간편진단(나이·소득·자산·무주택 요건)

### 회원 · 고객센터 · 관리자

- 일반 회원 / 공인중개사 탭 가입, 실시간 폼 유효성 검사, 데모 로그인 세션
- 마이페이지(프로필 수정, 찜 목록, 문의 내역), FAQ 검색·1:1 문의 접수
- 관리자 문의 답변·삭제 백오피스(`admin.html`)

### 공통 UX

- 공통 헤더·푸터, 디자인 토큰 기반 일관된 브랜드 톤앤매너
- 데스크톱·태블릿·모바일 반응형 레이아웃, 사기방지 하위 메뉴 활성 상태 표시

## 향후 개발 예정

- **매물 등록 고도화**: 4단계(기본정보 → 권리관계 → 사진 → 승인대기) 등록 폼, 관리자 승인·거래완료 처리
- **지도 재검색**: 지도 이동·줌 시 뷰포트 범위 내 매물 동적 필터링
- **등기부 OCR**: PDF·사진 업로드 → 소유주·근저당 자동 추출 및 전세가율 연동
- **AI 맞춤 추천**: 선호 조건 기반 안심 지역·매물 추천 챗봇, 생활권 분석 고도화
- **실서비스 인프라**: 이메일 인증, 비밀번호 해싱, JWT/세션 인증, 지오코딩, 사진 저장소
- **PWA 도입**: 모바일 앱형 구동, 찜 매물 가격·치안 등급 변경 푸시 알림
- **전문가 상담 매칭**: 위험 등급 매물 보고서를 중개사·안전 대리인에게 전송

## 개선 및 보완 계획

### 코드·UI 정리

- 헤더·푸터 CSS 중복 제거, `common.css` 디자인 토큰 단일 바인딩
- `index.html` ↔ `templates/` 간 상대 경로 통일(GitHub Pages·로컬 호환)
- 미로그인 사용자의 회원 전용 페이지 접근 시 `login.html` 리다이렉트

### 입력·예외 처리

- 회원가입 아이디 중복 검사, 오류 필드 자동 포커스
- 전세가율 계산기 0·음수·비숫자 입력 시 `NaN` 방지

### 현재 한계

- 일부 데모 기능은 `localStorage` 기반이며, 다중 사용자 공유 DB 미완
- 지오코딩·공인중개사 자격 검증·LH 공고 세부 자격 자동 추출 미구현
- 행복주택 자가진단은 공식 판정기가 아니며, 공모공고 원문 확인 필요
- Render 무료 플랜 cold start(약 1분), Aiven IP 필터 제한 등 인프라 제약

## 기대 효과

- **청년 세입자 사기 예방**: 복잡한 법률 정보 없이 위험 매물을 스스로 판별, 피해 사각지대 최소화
- **안심 주거 탐색**: 매물 스펙을 넘어 밤길 안전·치안시설 밀도 등 정량 지표 기반 주거 선택
- **청년 정책 활용도 제고**: 금융·주거 지원 정보를 한곳에서 확인, 공공 복지 수혜 확대
- **확장 가능한 아키텍처**: 데이터와 뷰 분리 구조로 백엔드 DB·AI 예측 모듈 연동 용이
